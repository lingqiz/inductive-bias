### Decision Data from Heimburg et al., (2025)
https://www.nature.com/articles/s41467-025-61792-0
Binary decision data from the mice cohorts reported in Fig.2

### Decision Type Code
    'Go Success' (Hit/True Positive) -> 11
    'Go Failure' (Miss/False Negative) -> 10
    'No-Go Success' (Correct Rejection/True Negative) -> 21
    'No-Go Failure' (False Alarm/False Positive) -> 20
    'Neutral Lick' -> 31
    'Neutral No Lick' -> 30

### Session Type Code
    1 - Habituation
    2 - Initial Rule
    3 - Neutral
    4 - Reversed Rule
